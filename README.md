
# Replication of "Nowcasting Macroeconomic Variables with a Sparse Mixed-Frequency Dynamic Factor Model"

A revised version of the code used for the simulation study in "Nowcasting Macroeconomic Variables with a Sparse-Mixed Frequency Dynamic Factor Model" by Dr. [Karsten Schweikert](https://github.com/karstenschweikert) and Domenic Franjic.

## Introduction

This repository contains the replication code for the following working paper:

Franjic, Domenic and Schweikert, Karsten, *Nowcasting Macroeconomic Variables with a Sparse Mixed-Frequency Dynamic Factor Model* (October 30, 2024), Last revised: 13 July 2026. Available at SSRN: [https://ssrn.com/abstract=4733872](https://ssrn.com/abstract=4733872) or [https://doi.org/10.2139/ssrn.4733872](https://doi.org/10.2139/ssrn.4733872).

## Repository structure

```text
ReplicationNowcastingMacroVarsWithSDFM/
├── Internals/                                  # C++ source and header files used by the simulation study
├── RHelper/                                    # R helper functions used in the empirical analysis
├── SimulationResults/                          # Simulation output used by the simulation-evaluation scripts
├── TwoStepSDFM_0.3.0.3.tar.gz                  # Exact package version used to generate the empirical results
├── EmpiricalStudyReplication.R                 # Main script for reproducing the empirical results
├── SimulationStudyReplication.cpp              # Main script for reproducing the main simulation results
├── SimulationStudyReplicationLassoOnly.cpp     # Main script for reproducing the lasso-only simulation results (see Online-Appendix)
├── GroupVariableImportance.R                   # Main script for reproducing the group importance plots
├── EvaluationSimulation.R                      # Produces the main simulation tables
├── EvaluationSimulationLassoOnly.R             # Produces lasso-only simulation robustness tables
├── README.md
└── LICENSE
```

## SimulationStudyReplication.cpp

This file, together with the routines in `./Internals/`, provides the code to reproduce the simulation results of the study.

### Prerequisites

#### C++ computing environment

- **Platform:** x86_64
- **Operating system:** Ubuntu 22.04
- **Linux kernel:** 5.15.0-190-generic
- **CPU:** Intel Xeon Gold 6348H @ 2.30 GHz
- **Logical CPUs:** 24
- **Compiler:** g++ 11.4.0
- **Parallelisation:** OpenMP with 24 threads
- **Random seed:** 18092024

#### C++ library dependencies

| Library | Version |
|---|---|
| Eigen | 3.4.0 |

An OpenMP-compatible C++ compiler, such as GCC or MSVC, is required.

### Installation

1. Install Eigen 3.4.0 or later.
2. Install an OpenMP-compatible C++ compiler.
3. Clone the repository:

```bash
git clone https://github.com/[USERNAME]/ReplicationNowcastingMacroVarsWithSDFM.git
cd ReplicationNowcastingMacroVarsWithSDFM
```

4. Compile the main simulation study on Linux:

```bash
g++ -std=c++14 -Wall -O3 -march=native -mfma -fopenmp -DNDEBUG \
    -I /path/to/eigen3 \
    SimulationStudyReplication.cpp \
    Internals/*.cpp \
    -o SimulationStudyReplication
```

5. Run the simulation:

```bash
./SimulationStudyReplication
```

To reproduce the lasso-only simulation results, compile and run `SimulationStudyReplicationLassoOnly.cpp` analogously.

### Usage

Most model parameters are specified at compile time. To change the simulation design, modify the hard-coded parameters at the beginning of `SimulationStudyReplication.cpp` or `SimulationStudyReplicationLassoOnly.cpp`.

### Data

The empirical analysis requires all available FRED-MD vintage files, available from the [FRED website](https://www.stlouisfed.org/research/economists/mccracken/fred-databases). In addition, the file `fred-qd_2024m12.csv` is required to obtain the transformation code for the US GDP level series.

Place the downloaded FRED-MD and FRED-QD files in the directories specified in the data-download block of `EmpiricalStudyReplication.R`. Uncomment and run this block once to download, preprocess, and restructure the data. It creates the intermediate files in `clean_data/`, which are subsequently used by the empirical-analysis and group-variable-importance scripts.

## Expected runtime

- **Simulation study (Table 1):** approximately 2–3 weeks, depending on the computing architecture.
- **Empirical analysis (Figure 1 and Table 2):** approximately 5–6 hours.
- **Group-variable-importance analysis (Figures 2–3):** approximately 10 minutes.

## Simulation reproducibility

The simulation code uses a fixed random seed (`18092024`). The simulations were compiled using CPU-specific optimisation (`-march=native`), fused multiply-add instructions (`-mfma`), and OpenMP parallelisation. Consequently, reruns on different hardware or software environments may yield small numerical deviations and are not guaranteed to be bitwise identical.

## Output files

The `SimulationResults/` directory contains the simulation output files used by `EvaluationSimulation.R` and `EvaluationSimulationLassoOnly.R` to produce the reported simulation tables.

The remaining manuscript outputs are generated by running the scripts listed in the "Code and manuscript outputs" section. Pre-generated empirical figures and tables are not included.
